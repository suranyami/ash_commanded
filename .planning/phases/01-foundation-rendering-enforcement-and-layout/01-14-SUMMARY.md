## Decisions Made

- Choose `:codepoints`: Ash's recommended value and the one that matches how SQL data layers
  count string length, so a `max_length` bound means the same thing on ETS- and
  Postgres-backed resources. `:mixed` would make the bound storage-dependent.
- Leave `mix.exs` constraints alone. Every constraint resolved the upgrade without blocking,
  and broad constraints are correct for a library that must install alongside `core`.
- Accept the resolver's additional moves (decimal 2.4.1 -> 3.2.0 and the ex_doc/ex_ast/finch/
  mint transitives) as part of the set; they are the resolver's answer, and narrowing the
  update would make the lock diverge from a fresh resolution.
- Delete the two regenerated `documentation/dsls/*.md` files, matching 01-11 and 01-12. Phase 7
  owns documentation reconciliation.
- Do not push. The CI observation is the orchestrator's next step.
