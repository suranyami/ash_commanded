## Trust Boundaries

| Boundary                       | Description                                                                                                |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| source tree to build tooling   | Four configuration files reference library source by literal path or module name and match by exact string |
| old namespace to new namespace | A bulk rename can rewrite strings that look like the target but are not                                    |

## STRIDE Threat Register

| Threat ID  | Category  | Component                                         | Severity | Disposition | Mitigation Plan                                                                    |
| ---------- | --------- | ------------------------------------------------- | -------- | ----------- | ---------------------------------------------------------------------------------- |
| T-01-BI-08 | Tampering | documentation groups and Dialyzer ignore paths    | high     | mitigate    | Fix in the same commit; verify by generating docs and running Dialyzer             |
| T-01-BI-09 | Tampering | bulk string substitution across the repository    | high     | mitigate    | Enumerated old-to-new module list; assert the DSL keyword and parity array survive |
| T-01-BI-10 | Tampering | stale compiled artifacts for old module names     | medium   | mitigate    | Clean rebuild once after the move                                                  |
| T-01-BI-11 | Tampering | neutrality proof skipped by the version exclusion | high     | mitigate    | Treat a zero-test golden render run as failure                                     |

### Mitigation detail

- T-01-BI-08: neither stale reference produces a compile error. The documentation groups produce no
  error at all and simply stop matching, which is the "looks done but is not" shape; the Dialyzer
  paths surface only at the slowest gate in the alias. Both are fixed in the same commit as the move
  and verified by actually running the tools rather than by reading the configuration.
- T-01-BI-09: a repository-wide substitution on the integration's name would rewrite the DSL block
  keyword D-15 locks, and could corrupt the parity script's expected-module array, which is derived
  from the fixture's own namespace and needs no change. The rename is applied from an enumerated list
  and the acceptance criteria assert both survivals directly.
- T-01-BI-10: a stale artifact for an old module name can satisfy a load check and make a broken tree
  look green. One clean rebuild removes the possibility.
- T-01-BI-11: the golden text-diff test carries the canonical-version tag, so on a non-canonical
  toolchain it is excluded and the neutrality proof silently becomes vacuous. A zero-test run is
  therefore treated as failure, not success.

</threat_model>
